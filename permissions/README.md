# Shell permissions

0-iam_betty: switch user to betty
1-who_am_i: print effective username
2-groups: print user groups
3-new_owner: change hello owner
4-empty: create empty hello
5-execute: add owner execute permission
6-multiple_permissions: set multiple permissions
7-everybody: add execute permission to everyone
8-James_Bond: set hello to 007
9-John_Doe: set hello to 753
10-mirror_permissions: copy olleh permissions
11-directories_permissions: add execute to directories
12-directory_permissions: create my_dir with 751
13-change_group: change hello group
14-change_owner_and_group: change owner and group
15-symbolic_link_permissions: change symbolic link owner and group
16-if_only: conditionally change hello owner
